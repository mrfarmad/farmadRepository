# config.example

Шаблонные конфигурации EDGE. После клонирования репозитория скопируйте каталог в рабочий `config/`:

```bash
cp -R config.example config
```

Далее обновите:
- `app_config.yaml` — системные параметры, RS-485 порт, расписания опроса
- `devices*.yaml` — реестр устройств, приоритеты, VFD профили
- `mitm_config.yaml` — параметры защиты сети (опционально)
- `secrets/` — зашифрованные секреты (создаёт `tools/first_start.py`)

Файлы внутри `config/` игнорируются Git и содержат чувствительные данные конкретного узла.
