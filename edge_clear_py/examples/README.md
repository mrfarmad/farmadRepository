# Examples directory

Здесь собраны шаблонные конфигурации и скрипты. Каталог `config.example/` в корне повторяет структуру рабочего `config/` (конфиги, логи, secrets) и служит ориентиром при развертывании. 

Эти файлы не используются рантаймом напрямую — скопируйте нужные шаблоны в `config/` (например, `cp -R config.example config`) и адаптируйте под своё окружение.
